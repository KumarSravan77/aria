# Investigation evidence order

Normalize report; identify customer journey; inspect changes; locate first CI/CD error; compare built, desired and live artifacts; inspect Kubernetes; correlate telemetry; retrieve authorized runbooks and verified memory; test alternatives; propose reversible mitigation; define recovery checks.

Use headings: Summary, Impact, Timeline, Evidence, Causal chain, Alternatives considered, Recommended actions, Recovery validation, Confidence, Unknowns.
